# Dron V5 Next.js Site

This is a Next.js App Router project built as a cinematic placeholder implementation of the uploaded V5 design spec.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`

## Notes

- Real images and videos are intentionally replaced with premium placeholder media blocks.
- Replace placeholder copy in `app/` and `components/site-data.ts`.
- Replace media placeholders with `next/image` or video embeds when ready.
